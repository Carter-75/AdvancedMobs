ABILITY SYSTEM STATUS: COMPLETE (Nov 22, 2026)

All 81 mobs have 5 brand new abilities each (405 total), implemented in code
under src/main/java/mod/advancedmobs/ability/, one package per mob. The old
special abilities (hunger_attack, horde_summon, piercing_shot, multishot,
ranged_potion_mastery, shadow_step, void_grasp, poison_mastery, creeper_power,
creeper_potion_cloud, void_bombardment) were removed from the code and from
all 81 JSON configs; the configs now hold only the upgrade trees.

HOW ABILITIES ARE GRANTED (AbilitySystem):
- Power fraction = lifetime earned points / abilityFullPowerPoints
  (ModConfig, default 3000).
- Normal mobs: chance of having any abilities = 1% at zero power, rising
  linearly to a 25% cap at full power.
- Accessible ability count by power fraction: below 0.30 = 1, 0.30-0.55 = 2,
  0.55-0.75 = 3, 0.75-0.90 = 4, 0.90+ = all 5. Grants are random, permanent,
  and only ever extend when a mob crosses into a higher bracket.
- Bosses (Ender Dragon, Wither, Warden, Elder Guardian, Mob Warlord): chance
  = 1% at zero power to 100% at full power, all 5 at full power. The Ender
  Dragon is guaranteed at least one ability from the very start. Bosses in
  active combat also earn points rapidly (dragon 25/s, wither and warlord
  15/s, warden and elder guardian 10/s).
- Only one ability fires at a time per mob, combat only. Cooldown starts when
  an ability finishes: 10 to 60 seconds, weighted shorter for stronger mobs.
- Master toggle: ModConfig abilitiesEnabled.
- Terrain rule: ability block changes are permanent and only happen when the
  level's mobGriefing game rule is on; with it off, no block changes and the
  other effects still run.

Full per-ability specs live in the code comments of each ability class and in
ABILITY-IDEAS.md. Build progress is tracked in IMPLEMENTATION-PROGRESS.md.
Everything is compile-verified with the javac harness; a real Gradle build
and in-game test on a PC are still pending.
